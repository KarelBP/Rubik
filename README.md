# About this reconstruction

This is an internet archaeology project. The original site disappeared after the hosting service ceased to exist. This repository is a restoration of the original rubik.rthost.org, created by Bob in 2003, based on archived copies
preserved by the Internet Archive's Wayback Machine.

Work in progress. Missing images are being re-created from the surrounding material and the described cube moves to match the original content as closely as
possible.

If you are the original author, or if you have additional materials, corrections, or copyright concerns, please write in the discussion.
